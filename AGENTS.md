# Agent rules

## Comments

- Don't write comments. Make the code explain itself through names and
  structure.
- Doc comments are the only exception, and they must follow Google style:
  - Swift: `///` comments as described in the
    [Google Swift Style Guide](https://google.github.io/swift/#documentation-comments).
    Start with a single-sentence summary, then use `- Parameter`,
    `- Parameters:`, `- Returns:` and `- Throws:` where they add information.
  - Shell: the file header and function comments described in the
    [Google Shell Style Guide](https://google.github.io/styleguide/shellguide.html#comments).
- Don't move explanations into Markdown or text files to work around this rule.
